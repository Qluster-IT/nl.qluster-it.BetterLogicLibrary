Добро пожаловать в Библиотеку Better Logic.

Это продвинутая библиотека логики с управлением переменными и библиотекой для Homey.

Это приложение снабжает ваш Homey Better Logic и Библиотеками:
* Управление переменными умным, интегрированным способом.
* Продвинутые карты действий и условий с Better Logic, такие как Math.js.
* Устройства для прямого управления переменными.
* Форматирование даты и времени, полностью настраиваемое, доступное для других приложений.
* Кодирование и выражения BLL для использования прямо внутри других потоков приложений.
* Пользовательские функции для использования в кодировании и выражениях BLL.
* Библиотеки для использования в кодировании и выражениях BLL, такие как Math.js и Lodash.
* Файловый сервер, который может использоваться другими приложениями, такими как Simple (Sys) LOG, чтобы предоставлять файлы в вашей локальной сети или загружать их в мобильное приложение Homey или в инструменты для разработчиков.
* Библиотеки для использования другими приложениями, уменьшающие размеры приложений и избыточности и улучшающие управление.
* API для управления переменными, с использованием Файлового сервера или других функций BLL.

Ознакомьтесь с (новыми) настройками приложения для всех возможностей и объяснений, таких как кодирование BLL в поддерживаемых приложениях!

Пример кодирования BLL: когда вы помещаете это в текстовый аргумент: - Привет, сегодня {[date("dddd")]} -, BLL автоматически найдет эти выражения в тексте и декодирует их, в результате получится - Привет, сегодня понедельник -.

Также: Управляйте переменными прямо в потоках!

Просто введите имя переменной в любую когда- и тогдокарту и выберите ее из списка: переменная будет автоматически создана.
Если вы хотите использовать тег, сначала нажмите сохранить.
Переменные, которые были автоматически созданы в потоках, будут также автоматически удалены, когда они больше не используются в потоках.
Переменными также можно управлять из экрана настроек. Эти переменные не будут автоматически удалены, если не используются, но их нужно удалять вручную.

И у кнопки "Удалить все" теперь есть подтверждение!

* Особенность: Добавлена поддержка API для GET, GET всех переменных и SET (пост) значения.
  * GET: HTTP://HOMEYADDRES/api/app/net.i-dev.betterlogic/VARIABLENAME
  * GET: HTTP://HOMEYADDRES/api/app/net.i-dev.betterlogic/ALL (Получить все переменные)
  * PUT: HTTP://HOMEYADDRES/api/app/net.i-dev.betterlogic/VARIABLENAME/VALUE  // Пожалуйста, убедитесь, что значение соответствует типу, иначе оно не будет установлено.
* Особенность: Триггер для API. Вызов
  * PUT для увеличения: HTTP://HOMEYADDRES/api/app/net.i-dev.betterlogic/trigger/VARIABLENAME Это вызывает данную переменную
* Особенность: Добавить увеличение или уменьшение к API. Вызов
  * PUT для увеличения: HTTP://HOMEYADDRES/api/app/net.i-dev.betterlogic/VARIABLENAME/i/VALUE  Увеличивает переменную на заданное значение
  * PUT для уменьшения: HTTP://HOMEYADDRES/api/app/net.i-dev.betterlogic/VARIABLENAME/d/VALUE  Уменьшает переменную на заданное значение
* Особенность: Добавить переключение логического значения (true->false или false->true) к поддержке API
  * PUT: HTTP://HOMEYADDRES/api/app/net.i-dev.betterlogic/VARIABLENAME/toggle Это принудительно изменит логическое значение

* Особенность: Добавить $timenow$ как специальную переменную для mathjs. Это получит текущее время в секундах с момента начала эпохи. Эта переменная не хранится в обзоре, а используется в выражениях.
* Особенность: Добавлены #DD (день), #MM (месяц), #YYYY (год), #HH (часы), #mm (минуты) #SS (секунды) как зарезервированные слова рядом с timenow в потоках mathjs. Теперь вы можете, например, присвоить #HH переменной, чтобы получить часы. Также я изменил timenow на #timenow для согласованности.
