Добро пожаловать в библиотеку Better Logic.

Продвинутая библиотека логики с управлением переменными и библиотеками для Homey.

Это приложение поставляет вашему Homey Better Logic и библиотеки:
* Управление переменными умным, интегрированным способом.
* Продвинутые карточки действий и условий с Better Logic, такие как Math.js.
* Устройства для прямого управления переменными.
* Форматирование даты и времени, полностью настраиваемое, общее с другими приложениями.
* BLL-кодирование и BLL-выражения для использования непосредственно в других приложениях.
* Пользовательские функции для использования в BLL-кодировании и BLL-выражениях.
* Библиотеки для использования в BLL-кодировании и BLL-выражениях, такие как Math.js и Lodash.
* Файловый сервер, который может быть использован другими приложениями, такими как Simple (Sys) LOG, для публикации файлов в вашей локальной сети или их загрузки на мобильное приложение Homey или в инструменты разработчика.
* Библиотеки, которые другие приложения могут использовать, уменьшая размеры приложений и дублирования и улучшая управление.
* API для управления переменными с использованием файлового сервера или других функций BLL.
* Карточки потоков для преобразования объекта/массива JSON в CSV или Excel.

Ознакомьтесь с (новыми) настройками приложения для всех функций и объяснений, таких как BLL-кодирование в поддерживаемых приложениях!

Пример BLL-кодирования: когда вы размещаете это в текстовом аргументе: - Привет, сегодня {[date("dddd")]} -, BLL автоматически находит эти выражения в текстах и декодирует их, получая - Привет, сегодня понедельник -.

Дальше: Управляйте переменными прямо в потоках!

Просто введите имя переменной в любое when- и thencard и выберите его из списка: переменная будет создана автоматически.
Если хотите использовать тег, сначала нажмите сохранить.
Переменные, которые были автоматически созданы в потоках, также будут автоматически удалены, когда больше не используются в карточках потоков.
Переменными также можно управлять с экрана настроек. Эти переменные не будут автоматически удалены, если не используются, но их нужно удалить вручную.

Особенность: Добавьте $timenow$ как специальную переменную для mathjs. Это вернет текущее время в секундах с начала эпохи. Эта переменная не сохраняется в обзоре, но используется в выражениях.
Особенность: Добавлены #DD (день), #MM (месяц), #YYYY (год), #HH (часы), #mm (минуты) #SS (секунды) как зарезервированные слова рядом с timenow в потоках mathjs. Теперь вы, например, можете назначить #HH переменной, чтобы получить часы. Также я изменил timenow на #timenow для согласованности.
